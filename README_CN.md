# OpenURWTest _(urwtest-rs)_

[English](README.md) | 简体中文

[![standard-readme compliant](https://img.shields.io/badge/readme%20style-standard-brightgreen.svg?style=flat-square)](https://github.com/RichardLitt/standard-readme)

用于 Windows 已挂载卷的质量与速度测试工具

OpenURWTest 提供两条独立测试线：**质量测试**通过写入确定性数据并校验来检查容量与坏块；**速度测试**按 CrystalDiskMark 风格测量顺序与 4K 随机写后读套件的带宽、IOPS 与延迟。程序提供终端 TUI 和命令行界面、多盘并发、温度与健康显示，以及 CSV/JSON/Excel/SVG 报告。Cargo 包名与可执行文件名仍为 `urwtest-rs`。

## 安全

- 质量测试会持续写入，直到可用空间不足 1 MiB，因此目标卷会被写满。
- 速度测试会创建指定大小（默认 4 GiB）的基准文件并执行直接 I/O。TUI 在结束后删除该文件；命令行会保留，除非手动清理目标目录。
- 只支持已挂载的卷路径，不会访问裸设备或分区表。
- 向包含 Windows 的卷写入时显示红色警告，并要求二次确认；其他固定磁盘显示黄色警告；可移动磁盘不显示额外警告。
- 速度测试只写入基准文件，不会写满卷。
- 质量测试运行中按 Esc 或 Ctrl+C 会先弹出确认框；确认取消后停止测试并保留已写入的数据。
- 请只在可以接受内容被覆盖的介质上运行。

## 安装

### 依赖

- Windows 10 或 11，x86_64
- Rust 1.96 或更高版本（仅从源码构建时需要）

构建可执行文件：

```sh
cargo build --release
```

可执行文件位于 `target\release\urwtest-rs.exe`。

## 使用

在终端中不带参数启动，会打开 TUI：

```sh
urwtest-rs
```

### TUI

首页列出已挂载的卷，每行显示复选框、挂载点、可用空间和设备型号。

| 按键 | 作用 |
| --- | --- |
| `Up` / `Down` | 移动光标 |
| `Space` | 勾选/取消当前卷 |
| `a` / `n` | 全选 / 清空 |
| `m` | 在质量测试与速度测试之间切换 |
| `Enter` / `w` | 打开设置对话框 |
| `r` | 重新扫描卷 |
| `q` | 退出 |
| `F2` | 开关鼠标捕获（关闭后可选择终端文本） |

右侧详情显示当前卷、可用空间、温度、健康状态、已选数量和测试类型。底部有可点击的“模式 / 测试设置 / 开始 / 退出”按钮。

### 质量测试

质量测试设置：

| 选项 | 说明 |
| --- | --- |
| 测试模式 | 写入并校验、仅写入、仅校验已有数据 |
| 圈数 | 1–99，默认 1；仅校验已有数据时固定为 1 |
| 出错后继续下一圈 | 默认否；仅在写入并校验且圈数大于 1 时可设置 |
| 成功后删除测试文件 | 默认否；仅在正常成功完成后删除 |
| 结束后自动导出报告 | 默认是；导出到 `./urwtest-export` 下的时间戳目录 |

设置完成后显示选项汇总。可移动磁盘在此确认后开始；固定磁盘显示黄色警告；包含 Windows 的卷显示红色警告，并需要第二个确认对话框。

运行页顶部显示目标、温度/健康与实时速度/剩余/ETA，随后是进度条、只保留最近三行的紧凑日志，日志下方是较大的带 Y 轴刻度的速度曲线。曲线 X 轴为已写入（或已校验）的字节位置：质量测试取开始时的剩余空间（空盘时即容量上限），速度测试取基准文件大小。结果页显示状态（PASS、FAIL、INCOMPLETE）、按写入位置或时间绘制的速度曲线、掉速事件以及掉速门限。`x` 切换图表横轴，`t` 切换门限模式，`[` 和 `]` 调整门限，`e` 导出报告。

默认掉速分析使用 80% 或 100 MB/s 的门限、150 ms 抖动滤除、90% 恢复线和 3 s 恢复窗口。

质量测试运行中按 Esc 或 Ctrl+C 会先弹出取消确认框。

### 速度测试

速度测试按 CrystalDiskMark 的四个预设执行：

| 预设 | 块大小 | 队列深度 | 线程 |
| --- | --- | --- | --- |
| SEQ1M Q8T1 | 1 MiB | 8 | 1 |
| SEQ1M Q1T1 | 1 MiB | 1 | 1 |
| RND4K Q32T1 | 4 KiB | 32 | 1 |
| RND4K Q1T1 | 4 KiB | 1 | 1 |

设置对话框是四项多选，一次运行可以按顺序执行多个预设；默认全选。测试文件大小默认 **4 GiB**，可选 1、2、4、8 GiB。

Q8/Q32 由 8/32 个同步 QD1 工作线程模拟，不是单线程原生异步队列；数值适合做相对比较，不能直接与 CrystalDiskMark 的队列模型互换。

吞吐量按阶段墙钟时间计算：包含数据生成，读取阶段还包含校验工作；单笔 I/O 延迟不含比较本身。在非常快的介质上，数据生成/校验的 CPU 开销仍可能影响吞吐结果。

设置 `URWTEST_ASCII=1` 可在缺少 braille/框线字形的终端上使用 ASCII spinner 和图表点。

每个预设都是完整的写后读流程：

1. 写满整个文件（计时）；
2. 读回并逐块校验（读取计时；比较不计入 I/O 时间）。

顺序项发现读取或校验错误时，立即停止该盘的整套速度测试，结果标红，并记录出错位置的写入量；开启“顺序项错误继续”后继续跑完。随机 4K 项的错误只记录日志，不中断测试。

所有预设运行中都显示写入/读取折线图。运行阶段使用 braille spinner；运行中的 QC tab 用旋转象限，SC tab 用迷你音量柱。错误状态脉冲一次后保持红色。套件结束后，结果页同时叠加显示顺序项写入/读取曲线和四个 4K 柱；随机柱取去掉最高值与最低值后的平均数。进度条用红色标出错误位置。

### 多盘测试

- 用 `Space` 勾选要测试的卷，`Enter` 把设置应用到所有已选卷。
- 每个盘独立线程、独立取消令牌、独立 tab。
- 运行页用 `Tab` 切换 tab，`1`–`9` 直达。
- `Esc` 和 Ctrl+C 会打开取消提示；`Enter` 或 `1` 停止当前盘；超过一个盘时 `2` 或 `S` 停止全部；`3`/`Esc` 返回。
- 只运行一个盘时，提示框只有“Enter 停止当前盘”和“Esc 返回”，没有数字编号，也没有“停止全部”。
- 全部完成后显示多盘结果表；按 `e` 导出多盘报告，自动导出由质量测试设置控制。
- 速度测试同样会在已选盘上并发执行。

### 鼠标

- 默认开启鼠标捕获，`F2` 切换。
- 左键：在首页移动光标、勾选复选框；点击设置字段；点击 tab；点击底部区域执行开始、停止、取消、返回、导出。
- 滚轮：滚动卷列表、切换设置字段、切换盘 tab，或在结果页调整掉速门限。
- 悬停时按钮和行会高亮。
- 鼠标设计只包含左键、滚轮和 `F2`。

### 命令行

```sh
# 列出已挂载的卷
urwtest-rs list

# 查看型号、容量、磁盘号、温度与健康
urwtest-rs info --target C:\

# 写入并校验
urwtest-rs run --target E:\

# 仅写入
urwtest-rs run --target E:\ --no-verify

# 两圈，校验出错时继续下一圈
urwtest-rs run --target E:\ --passes 2 --continue-on-error

# 校验已有的测试数据
urwtest-rs verify --target E:\

# 默认 CDM 套件：四项全选，4 GiB 文件
urwtest-rs speed --target E:\ --size 4g

# 只跑两个顺序预设，2 GiB 文件
urwtest-rs speed --target E:\ --preset seq1m-q8t1 --preset seq1m-q1t1 --size 2g

# 两个随机 4K 预设，顺序项出错时继续
urwtest-rs speed --target E:\ --preset rnd4k-q32t1 --preset rnd4k-q1t1 --size 1g --ignore-errors

# 两个盘并发跑套件，JSON 数组输出
urwtest-rs speed --target E:\ --target D:\ --size 4g --json

```

| 参数 | 说明 |
| --- | --- |
| `--target <PATH>` | 卷根目录或目录；速度测试可重复指定多个 |
| `--passes <N>` | 质量测试圈数，默认 1 |
| `--no-verify` | 质量测试仅写入，不校验 |
| `--continue-on-error` | 校验出错时继续下一圈 |
| `--progress auto\|live\|plain\|off` | 进度输出模式 |
| `--no-tui` | 即使当前是终端也使用文本界面 |
| `--export <DIR>` | 质量测试结束后导出 CSV/JSON/Excel/SVG 报告 |
| `--color auto\|always\|never` | 控制终端颜色 |
| `--preset <NAME>` | CDM 预设：`seq1m-q8t1`、`seq1m-q1t1`、`rnd4k-q32t1`、`rnd4k-q1t1` 或 `all`；可重复或逗号分隔，默认四项全选 |
| `--size <SIZE>` | 测试文件大小，默认 `4g`；常用 1、2、4、8 GiB |
| `--ignore-errors` | 顺序项首次读取/校验错误后继续测试 |
| `--seed <N>` | 覆盖工作负载随机种子 |

标准输出不是终端，或使用 `--no-tui` 时，质量测试使用文本界面。

## 测试数据

### 质量测试

- 文件名：`HUT00001.BIN`、`HUT00002.BIN`……（5 位序号）
- 块大小：1 MiB；每个文件最多 2048 块（2 GiB）
- 总块数：`最后一个文件大小 / 1 MiB + (文件数 - 1) * 2048`
- 数据：固定种子的确定性序列；校验时按同一序列重建并逐字节比较
- 校验只识别上述连续编号的测试文件，其他文件不会被删除

### 速度测试

- 基准文件：目标目录下的 `BENCH0001.DAT`
- 数据：确定性非零 pattern
- 默认使用直接 I/O；块大小与偏移按无缓冲访问对齐
- TUI 结束后删除基准文件；命令行保留

## 报告

单盘质量测试导出：

| 文件 | 内容 |
| --- | --- |
| `samples.csv` | 重采样后的速度序列：位置、时间、速度、基线、门限 |
| `events.csv` | 掉速事件 |
| `report.json` | 运行统计、分析参数和导出结果 |
| `report.xlsx` | Excel 工作簿：Summary、Samples、Events 三个工作表 |
| `speed_position.svg` | 按写入位置的速度图 |
| `speed_time.svg` | 按时间的速度图 |

多盘质量或速度测试导出到 `urwtest-export/<timestamp>/multi/`：

| 文件 | 内容 |
| --- | --- |
| `multi_summary.csv` | 每盘一行；速度测试每个预设一行：模式/预设、状态、字节数、错误、温度、健康、速度指标 |
| `multi_report.json` | 同样内容的 JSON |
| `multi_report.xlsx` | 含 Summary 工作表的 Excel 工作簿 |

## 平台

- 当前目标平台为 Windows 10/11 x86_64。
- Linux 代码保持可编译，通过 `cargo check --target x86_64-unknown-linux-gnu --all-targets` 检查。
- 温度与健康从 Windows 存储属性读取；部分 USB 桥接或可移动设备不提供温度，显示 `unknown`。
